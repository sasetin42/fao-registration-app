# Firebase Migration Plan

## Goal
Migrate the FAO Event Registration application completely from Supabase (PostgreSQL) and Vercel hosting to Firebase (Firestore, Storage, and Firebase Hosting) while maintaining existing functionality.

## Project Type
**WEB** / **BACKEND** (Node.js/Express Serverless API hosting transition)

---

## 1. Analysis (Phase 1)

### Environment Mapping
- **Source Environment**: Supabase (PostgreSQL database, REST endpoints) & Vercel hosting.
- **Target Environment**:
  - Database: Firestore (`fao-online` database instance in `fao-registration` project).
  - Storage: Firebase Storage (`gs://fao-registration.firebasestorage.app`).
  - Hosting: Firebase Hosting (`fao-registration.firebaseapp.com` / custom domain).

### Relational Schema to Document Schema Mapping
1. **`registration_list`** collection:
   - Unique key: `id` (string generated by Firestore or auto-incrementing equivalent mapping).
   - Document ID: We can use the registration's email or a generated document ID.
   - Fields: Map relational columns directly to document properties (e.g., `email`, `first_name`, `approval_status`).
2. **`attendance_keys`** collection:
   - Fields: `created_at`, `participant_id`, `visitor_code`, `attendance_key`.
3. **`zoom_registrations`** collection:
   - Fields: `created_at`, `user_id`, `join_url`.
4. **`attendance_logs`** collection:
   - Fields: `created_at`, `participant_id`, `scanned_at`, `scanned_by`.

### Dependency Changes
- Add `"firebase": "^10.x.x"` to `package.json` dependencies.
- Remove any axios-based manual REST wrappers targeting Supabase.

## 3. Solutioning (Phase 3)

### Firebase Helper Interface (`api/services/firebase.js`)
We will implement standard collection functions mapping to the original `supabase.js` functions:
- `insert(collectionName, data)`
- `select(collectionName, match, selectCols, opts)`
- `update(collectionName, data, match)`
- `remove(collectionName, match)`
- `updateBatch(collectionName, data, keyCol, values)`
- `removeBatch(collectionName, keyCol, values)`
- `saveZoomDetails(userId, joinUrl)`

Using the Web/Client SDK:
